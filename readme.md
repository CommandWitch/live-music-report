## Live Music Catalogue & Report Tool

> Query, store, and report on live music on iTunes with Python + SQLite.

## Overview
This project creates a searchable catalogue of live music entries, stores data locally in SQLite, and generates formatted reports. Built as practice for Python scripting, database operations, error handling, and version control with Git/GitHub.

## Features
- SQLite database for persistent, structured storage
- Custom queries to filter and analyse data
- Subprocess execution with timeout protection
- Clean error handling and formatted output
- Local notes and database files kept private via `.gitignore`

## Built With
- Python 3.14
- SQLite3 (built-in — no extra install)
- PowerShell / VS Code
